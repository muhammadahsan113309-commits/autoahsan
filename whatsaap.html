Automation Workflow

Browsers cannot open local .py files directly due to OS security boundaries. Choose one of two methods below to trigger Python automatically:

Method A: Auto Startup (Easiest)

Add a batch launcher to your Windows Startup folder so server.py runs silently in the background when your laptop turns on.

Method B: Cloud Listener (Firebase)

Send messages from anywhere outside! Python listens to Firestore database updates and triggers WhatsApp when you submit from your phone.

How to Automate Server Opening

1. Automatic Laptop Startup (Recommended)

Make server.py automatically start in the background when you turn on your laptop:

  1. Press Win + R, type shell:startup and press Enter.
  2. In that folder, create a new text file named run_whatsapp.bat.
  3. Paste the following code into the file and save: 
    @echo off
py "C:\path\to\your\server.py"
pause

2. Remote Control via Firebase (When Away)

If you want to send messages from outside using your smartphone:

  • Your HTML page writes a document to Firestore: db.collection('queue').add({ phone, message })
  • Your Python script on your laptop runs firestore.on_snapshot() to listen for new entries in real time.
  • When you submit on mobile, Python detects the new entry on your laptop and triggers WhatsApp instantly!
